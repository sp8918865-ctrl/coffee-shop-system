# Coffee Shop Management System

Sistem manajemen operasional coffee shop yang mencakup POS (Point of Sale), KDS (Kitchen Display System), dan manajemen inventaris.

## Tech Stack
* **Language/Framework**: PHP / Laravel / HTML / CSS / JS
* **Database**: MySQL (InnoDB, 3NF)
* **Version Control**: Git & GitHub

## Cabang Pengembangan (Branch Strategy)
* `main`: Production release
* `develop`: Staging & integrasi fitur
* `feature/frontend`: Pengembangan antarmuka UI/UX
* `feature/backend`: Pengembangan API & logika database
